# Smart civic

Build a responsive website for reporting road issues such as potholes, broken streetlights, or damaged sidewalks. The site should include:



1. **Complaint Form Section**

   - Input fields for name, contact details, and type of issue.

   - A text box for detailed description of the problem.

   - A suggestion box for citizens to propose improvements.



2. **Image Upload Section**

   - Allow users to upload one or more photos of the road problem.

   - Support common formats (JPEG, PNG).



3. **Live Location Capture**

   - Integrate a map with GPS functionality to automatically detect and attach the user’s current location.

   - Option to manually pin the location if GPS is unavailable.



4. **Submission & Tracking**

   - A “Submit Complaint” button that stores the complaint in a database.

   - Generate a unique complaint ID for tracking.

   - Provide confirmation to the user after submission.



5. **Admin Dashboard**

   - Section for authorities to view, filter, and manage complaints.

   - Display complaint details, images, and location on a map.



6. **Design Requirements**

   - Clean, user-friendly interface.

   - Mobile-first responsive design.

   - Use clear icons for upload, location, and submission.
